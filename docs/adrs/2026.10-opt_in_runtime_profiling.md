# Opt-in runtime profiling

- Date: 2026-10-20
- Status: accepted

## Context

Production idle load needs CPU profiles from the affected process rather than
source-level guesses. Both the standalone app and SaaS wrapper share server startup.

## Decision

Mount pprof at `/<secret>/debug/pprof/` on the existing application server when
`SIMPLEDMS_PPROF_PATH` specifies a nonempty URL-safe segment. Reuse the router's session/transaction wrapper and
require a full system-admin session. Finish authorization before handing the
request to the standard pprof handlers.

## Rationale

This reuses Go's profiling tools and existing authentication without another port,
SSH tunnel, or container network-namespace access. Captures stream directly after
the short authorization transaction completes.

## Consequences

- Both applications can collect production profiles with no new dependencies.
- Profiling access is disabled by default, requires the configured secret path,
  and is limited to system administrators; CPU sampling starts only on request.
- Changing the setting requires a restart. Captures require a valid app session
  and may need a longer reverse-proxy response timeout.
